# 音频配置

交付的 156 条 WAV 保存在 `Assets/_LifeLine/Audio`，原始文件名和分类目录保留。用途、循环和来源可查阅同目录里的 `AUDIO_MANIFEST.md` 和 `AUDIO_SOURCES.md`。

- **替换音效**。在 `Assets/_LifeLine/Data/Audio/SoundLibrary.asset` 找到对应 Cue，在 Inspector 里替换 AudioClip 或调整单条音量。角色、环境、设备、战斗和 UI 都会从这里读取音效。
- **配置背景音乐**。打开 `Assets/_LifeLine/Prefabs/Audio/VoyageAudio.prefab` 的 `BGM Manager`，在 Tracks 中给 Menu、Day、Night、Storm、Underwater、Cave、Rescue 填写曲目。每个场景状态可设置曲目音量，`Fade Seconds` 控制游戏内状态切换时的交叉淡入淡出。当前背景音乐槽留空，两条结局提示归入音效。
- **调节混音**。主菜单和游戏内暂停菜单都可以打开设置，调节主音量、音效和音乐。主音量作用于两个音频通道，玩家偏好独立于航程存档。环境声和结局音效跟随音效滑杆。
- **水下冲刺喘息**。满氧默认每 4 秒播放一次，间隔随剩余氧气线性缩短，最低为音频原长约 1 秒。可在 `VoyageAudio` 预制体根节点的 `Sprint Breath Interval` 调整满氧间隔。
- **检查联机**。环境循环按本机角色所在位置播放。双方共享的动作音效由房主发送事件，来宾按位置播放并去重。旋钮与页面操作等界面反馈在本机播放。

音效列表、音源、音量滑杆和曲目槽均可在编辑器里查看。重新导入音频时，保留已调整过的音效配置与曲目引用。
