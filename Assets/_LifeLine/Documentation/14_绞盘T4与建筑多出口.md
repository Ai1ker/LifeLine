# 绞盘T4、总控升级预览与建筑多出口

更新：2026-11-17。本文件覆盖此前文档中绞盘最高T3、74m末级绳长和普通建筑外部洞口的对应说明。

## 绞盘T4

- 全等级绳长：基础28 / T1 44 / T2 54 / T3 74 / T4 100m。`GameTuning.ropeLengths`公开可调。
- T4沿用每级2纤维束的升级费用。到T4后满级，禁止继续花费材料升级；存档接受T4并拒绝越级T5。
- T4相对T3拉回效率+20%，`GameTuning.winchT4RecoveryBonus=.2`。被动手摇收绳、电动收绳、成功QTE增加的距离及结局救援进度均乘1.2；失败QTE回滑距离保持原值，不扩大惩罚。
- 每目标效率为`WinchRecoveryMultiplier / max(1, WinchTargetCount)`：T4挂1/2/3个目标时分别为120% / 60% / 40%。潜水员和挂绳货箱仍同时回收。
- 电路和电量满足时继承T3自动回收与连续3次拖拽信号；无电保留手动校准。电动关闭设备面板后继续回收。
- 旧T3存档仍为T3、74m，不自动赠送T4。Unity编辑器菜单`LifeLine/Balance/Apply Winch T4 (Preserve Custom Values)`只给不足5项的绳长数组补末级100，保留前面自定义值与已有T4自定义值；旧生存平衡迁移菜单也包含该补充。

## 总控升级UI

每项显示“设备名 → 下一等级 / 下一等级的效果”与对应费用。满级显示当前等级和“已满级”，按钮禁用，不显示空费用或后续效果。

`Runtime/UI/UpgradeSummary.cs`从真实public参数计算下一步的绳长、氧气、耐久、航速/漂移、背包格子/采集、潜水服和制作时间。T1制作台只预览30s与判定+30%；T2只预览20s；T3只预览15s和双作业。绞盘在T3时才预览T4的100m与效率+20%，不会在低等级同时罗列后续全部效果。探照灯已内置T1，故默认下一升级显示T2。

文案保留在DefaultLocalization SO中供开发者编辑，中英随系统/游戏语言切换。新增词条以`upgrade.*`为键，不覆盖已有手工译文。

## 普通建筑四向出口

- 三海区、三水深段的9栋普通建筑，每栋至少有顶部、底部、左侧、右侧各1个出口，即至少4个出口。所有出口通向同一棵连通房间图，保留内部迷宫与可交互活板门。
- 顶部入口保留原格子，底部出口列随当天种子随机。相邻海区的左右主洞口继续成对、同高度连接。
- 左右侧各有55%概率额外增加1个不同房间的洞口，`WorldGenerator.extraSideOpeningChance`控制额外洞口，不再决定是否有基本侧口。最深最右建筑朝向支路洞穴的一面只保留安全的主洞口，避免额外开口正对洞穴墙。
- 每海区上下建筑除原来的外侧绕行路线外，再加顶部/底部相连的水道。在建筑间留白处转向，不穿越墙体。普通地图共有18条跨海区/跨水深段路线；有洞穴时19条。
- 洞穴保留1个侧面入口、独立迷宫、尽头电鳗和守卫，不应用普通建筑的四向出口。
- 新出口使用独立的日种子随机流，不改变原房间生成图、奖励路径和物资/货箱的确定性ID。开口视觉与碰撞读取同一`MazeLayout.ExteriorExits()`数据。
- 生成检查对所有外部洞口执行完整角色胶囊净空检查；跨栋路线逐段检查实际碰撞。洞口外检查点停在整个角色离开墙体的位置，避免穿出窄建筑间隙后继续走到下一栋未对齐的墙上。边界、50m资源深度和末级绳长检查继续执行。

## 验证入口

EditMode `WinchAndRuinExitTests`覆盖费用、存档等级、保留自定义数组、下一级提示，以及4个种子的四向出口/单入口洞穴与实际胶囊通行。

PlayMode `CargoLifelinePlayModeTests`新增T4无电手摇/有电自动、单目标/三目标、成功QTE与失败回滑实测。规则与生成净空检查可继续使用现有开发菜单。
