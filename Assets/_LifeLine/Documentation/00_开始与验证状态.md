## 打开和运行

项目：`E:/UnityProject/LifeLine`，编辑器：Unity **6000.6.1f1**。实际安装 Input System **1.20.0**、Cinemachine **6.6.0**、URP **17.6**。

1. 打开 `Assets/_LifeLine/Scenes/MainMenu.unity`，点击编辑器 Play。
2. 点击“开始本地双人”。P1 船长 WASD / W 跳跃 / E 互动（水下按住E采集，固定4格）；P2 潜水员方向键 / ↑ 跳跃 / Enter互动与藏匿 / 1 采集 / 2 鱼枪。
3. 船上默认同屏，ESC暂停菜单的设置中可切分屏并保存。任一角色入水后本地双人自动分屏，两人都回船后恢复船上偏好。
4. 设置提供“跟随系统 / 简体中文 / 英语”，默认跟随系统；“键位 / 换绑”分别修改两位角色并保存。设备面板打开时先按ESC关设备，再按ESC暂停；暂停后再按ESC继续。
5. 每日白天自动保存一次；ESC的“手动存档”覆盖同一槽，有有效存档时主菜单才显示“继续游戏”。开始新航程经渐入过场进入玩法，并在第1日自动替换旧槽。
6. 开发测试按F8：立即切换天数/强制雷雨、传送船舱、补给、造挂绳货箱、召唤深影、下一天必出洞穴或城区过滤器、双方无限氧气、加速，以及跳过当前设备QTE／立即完成当前互动。执行命令自动隔离测试存档；见08，删除单独Development文件夹即可移除，相关测试自动跳过。

主菜单的「联机模式」可创建或加入 Steam 双人房间。按职责各选一人，房主开始航程。联机使用各自全屏及独立的 WASD 改绑方案。操作、依赖和验证范围见[04_P2P接口与后续接入.md](04_P2P接口与后续接入.md)。
