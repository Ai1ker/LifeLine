# 一线生机 · 开发与测试入口

更新日期：2026-11-16。当前阶段为 Unity 本地双人基础可玩版本，使用明亮几何占位、UGUI 和可替换的角色表现接口。

## 打开和运行

项目：`E:/UnityProject/LifeLine`，编辑器：Unity **6000.6.1f1**。实际安装 Input System **1.20.0**、Cinemachine **6.6.0**、URP **17.6**。

1. 打开 `Assets/_LifeLine/Scenes/MainMenu.unity`，点击编辑器 Play。
2. 点击“开始本地双人”。P1 船长 WASD / W 跳跃 / E 互动；P2 潜水员方向键 / ↑ 跳跃 / Enter 互动 / 1 采集 / 2 鱼枪。
3. 船上默认同屏，ESC暂停菜单的设置中可切分屏并保存。潜水员入水后本地双人自动分屏，船长绞回后恢复船上偏好。
4. 设置提供“跟随系统 / 简体中文 / 英语”，默认跟随系统；“键位 / 换绑”分别修改两位角色并保存。设备面板打开时先按ESC关设备，再按ESC暂停；暂停后再按ESC继续。
5. 每日白天自动保存一次；ESC的“手动存档”覆盖同一槽，回主菜单选“继续游戏”恢复最近进度。开始新航程会在第1日自动替换旧槽。

当前主菜单没有单人辅助、无尽模式或尚未接通的在线入口。实际场景已加入 Build Settings，MainMenu 在前、Gameplay 在后。

Windows开发版：`E:/UnityProject/LifeLine/Builds/Windows/LifeLine.exe`。保留同目录的`LifeLine_Data`、`MonoBleedingEdge`及UnityPlayer等依赖一起运行，不能只复制exe。2026-11-16已更新碰撞绳、独立地图、货箱吊索及双视图绞盘连接；Windows x64 Mono构建0错误。8项警告为Unity 6.6对象查询API弃用提示，不影响本次构建。

## 本轮实际验证

以下结果来自连接的 Unity 编辑器，非仅 C# 静态编译：

- EditMode **32 / 32 通过**：原有本地化/输入/存档检查，新增独立地图的坐标与旧档兼容、跨图战斗、绳路接触点存档、活板门破坏保存及恢复。
- PlayMode **25 / 25 通过**：原有10项输入、摄像机、ESC和表现检查；新增7项碰撞绳绕墙/限长/门/货箱物理、5项独立地图与缩略船生命周期、3项装货挂绳精确入库/绞盘破门/信号目标优先级的实际集成检查。
- PlayMode在编辑器失焦状态通过。虚拟输入测试临时隔离焦点并在finally恢复设置，游戏默认输入行为不变；Test Runner摘要保存在工作目录`artifacts/Validation/`。
- GameSession / CraftingManager 真实组件规则检查 **71 项通过**：费用、40 秒自动 / 约 10 秒完美制作、取消不退材料、3 秒手摇与升级保留、4 故障免费重修、绞盘接回及失败回滑、5 秒救助、深影刷新条件、自然第 4 日救援结局；另有跨三海区鲨鱼分配回归检查。
- 实际地图物理检查 **10 个布局（含强制洞穴）、284 个房间、312 个通道、13条跨区域路线**通过角色胶囊净空检查；**100 个横门、104 个竖门**验证闭门阻挡、开门通行；每日种子、权重、掉落与挂载货箱保留通过。额外4个种子验证横口随机变化与实际通行。
- Camera Rules：船上同屏默认、设置切换、入水强制分屏、登船恢复、在线视图接口按本地角色全屏，以及偏好持久化通过。
- 真实场景检查：主菜单进入 Gameplay；初始 20% 电、40 秒氧、8 格背包；中文系统自动中文、英文切换无未翻译中文；站点中英标签；夜潜无灯 60 像素视野与有效 T2 灯关闭黑幕。
- 真实存档场景链：第1日自动存、暂停按钮手动覆盖、主菜单继续、材料及未完成制作恢复、同日不重存、第2日刷新后自动存通过。过滤器首次打开生成20块管道，保存解对应入口出口可连通。试玩验证后留下正常第1日初始自动槽。

这些检查覆盖规则与关键输入/物理链路。人工完整双人航程、不同屏幕比例排版、手感平衡仍应按 03 清单持续试玩。

## 保存与重新生成

正常 Play 不重建已编辑的资产。`LifeLine/Create First Playable (Preserve Existing)` 保留已有场景、配方和预制体；更新默认配色与旧规则使用 01 中对应的显式命令。需要重新生成场景时，先保存人工改动；覆盖生成会备份旧场景到 `Documentation/SceneBackups`。

在 Gameplay 场景用 `LifeLine/Documentation/Export Current Tuning` 重新导出实际 Inspector 数值到 02。修改配方请先确认配方 id 与功能标记，避免已有任务和 UI 引用失配。

工作目录里的 `UnityGameStaging` 只同步源文件与 Markdown，导入工具不会覆盖 Unity 的 `.meta`、SO、场景和预制体。已修改源文件会备份到工作目录 `artifacts/UnitySourceBackups`。
