# 一线生机 · 开发与测试入口

更新日期：2026-11-17。当前阶段为 Unity 本地双人基础可玩版本，使用明亮几何占位、UGUI 和可替换的角色表现接口。

## 打开和运行

项目：`E:/UnityProject/LifeLine`，编辑器：Unity **6000.6.1f1**。实际安装 Input System **1.20.0**、Cinemachine **6.6.0**、URP **17.6**。

1. 打开 `Assets/_LifeLine/Scenes/MainMenu.unity`，点击编辑器 Play。
2. 点击“开始本地双人”。P1 船长 WASD / W 跳跃 / E 互动；P2 潜水员方向键 / ↑ 跳跃 / Enter 互动 / 1 采集 / 2 鱼枪。
3. 船上默认同屏，ESC暂停菜单的设置中可切分屏并保存。任一角色入水后本地双人自动分屏，两人都回船后恢复船上偏好。
4. 设置提供“跟随系统 / 简体中文 / 英语”，默认跟随系统；“键位 / 换绑”分别修改两位角色并保存。设备面板打开时先按ESC关设备，再按ESC暂停；暂停后再按ESC继续。
5. 每日白天自动保存一次；ESC的“手动存档”覆盖同一槽，回主菜单选“继续游戏”恢复最近进度。开始新航程会在第1日自动替换旧槽。
6. 开发测试按F8：立即切换天数/强制雷雨、传送船舱、补给、造挂绳货箱、召唤深影、下一天必出洞穴、加速。执行命令自动隔离测试存档；见08，删除单独Development文件夹即可移除。

当前主菜单没有单人辅助、无尽模式或尚未接通的在线入口。实际场景已加入 Build Settings，MainMenu 在前、Gameplay 在后。

Windows开发版：`E:/UnityProject/LifeLine/Builds/Windows/LifeLine.exe`。保留同目录的`LifeLine_Data`、`MonoBleedingEdge`及UnityPlayer等依赖一起运行，不能只复制exe。2026-11-17更新本轮绳索性能、HTML维修板、炮塔T2、深影三攻击、固定雷击预警、渐进修船、失败恢复及双语数值HUD。本次同时更新双人下水、按键藏匿、T3手动保留、夜晚背景及下一天必出洞穴。最新生态改动包括洞穴必出电鳗/白化鲨守卫、鱼获/食人鱼、2/3命中逃跑、米制索敌、敌人穿墙和不透明夜潜遮罩。Windows x64 Mono开发构建包含F8工具，174.20MiB，0错误；10项弃用提示（8项现有对象查询API、2项DEVELOPMENT_BUILD条件编译提示），功能验证通过。

## 保存与重新生成

正常 Play 不重建已编辑的资产。`LifeLine/Create First Playable (Preserve Existing)` 保留已有场景、配方和预制体；更新默认配色与旧规则使用 01 中对应的显式命令。需要重新生成场景时，先保存人工改动；覆盖生成会备份旧场景到 `Documentation/SceneBackups`。

在 Gameplay 场景用 `LifeLine/Documentation/Export Current Tuning` 重新导出实际 Inspector 数值到 02。修改配方请先确认配方 id 与功能标记，避免已有任务和 UI 引用失配。

工作目录里的 `UnityGameStaging` 只同步源文件与 Markdown，导入工具不会覆盖 Unity 的 `.meta`、SO、场景和预制体。已修改源文件会备份到工作目录 `artifacts/UnitySourceBackups`。
