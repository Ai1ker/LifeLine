# 开发测试工具

2026-11-18。进入本地航程后按F8开关，可拖动标题栏。仅在Unity编辑器和Development Build编译；普通正式构建不包含工具。使用新版Input System检测F8，游戏角色键位不受影响。工具按钮和说明自动跟随游戏中英语言设置。

同日后续拾取、4秒救助、昼夜卡顿与地图覆盖验证见[16_拾取救助与昼夜优化.md](16_拾取救助与昼夜优化.md)。F8强制恢复船员属于开发命令；验证“昏厥绞回后仍倒地”时不要点击恢复按钮，应真实持续互动4秒扶起。跳日与完整地图几何验证成本分别记录，不能把显式验证耗时当作正常每帧成本。

| 操作 | 行为 |
| --- | --- |
| 跳过当前设备QTE（开关） | 持续完成当前已打开设备中的有效交互；仍检查设备解锁、配方入队和维修授权 |
| 立即完成当前互动（按钮） | 单次完成当前对应设备的有效交互，不改变其他站点的作业 |
| DAY − / + | 立即应用测试天数1–99，保持当前日内进度；同步更新elapsed/previousDay并刷新对应地图与鲨鱼 |
| 白天 / 雷雨夜 | 跳到所选日白天10%或夜晚开始后全天周期2%的位置；测试按钮显式强制所选日雷雨，普通玩法仍为第2夜必出、第4日起10%；刷新该日地图 |
| 两名船员移入船舱 | 船体局部位置(-3,-3.1)/(3,-3.1)，保留正常跳跃与互动 |
| 添加材料和燃油 | 木材、金属、纤维、木板、铁板、纤维束、燃油各+10；数量可调 |
| 恢复耐久、电力、氧气和船员 | 耐久与电力补满、两人扶起、重置潜水员承伤及昏厥，角色保持当前船上/水下归属 |
| 生成两个已挂绳货箱 | 船底左右各2m、深4m，各含1木材，参与真实绳路与牵引，用于验证1/N分速 |
| 召唤深渊之影 | 进入至少第4日夜晚并直接生成影子，用于测试三种攻击；不要求满足自然主线/海域门控 |
| 下一天（必出洞穴） | 跳到下一日白天10%，仅该日必出洞穴；洞穴尽头必出电鳗；覆盖随测试存档保存 |
| 正常速度 / 4倍速度 | 推进实际模拟时间；暂停时不会强制恢复游戏 |

工具没有自动无敌、自动补电或更改掉落概率；恢复按钮是一次性命令。雷雨、鲨鱼和氧气规则仍正常运行。跳日刷新地图会改变当前测试局，应先保存需要保留的正式进度。

## 本批新增：跳过设备QTE

先正常打开已解锁设备，再打开F8面板勾选“跳过当前设备QTE”，或点击一次“立即完成当前互动”。制作／维修台只完成已付款入队的当前站点作业；引擎、电路、过滤器仍须正常授权并支付费用；绞盘完成当前回收目标，手摇执行有效发力，钓鱼只完成已经开始的钓鱼交互。未制造的设备不能借此解锁，材料不足不能免费维修，开着制作台不会替别的设备完成交互。

正常的设备建造、鱼叉消耗和资源成本均保留。开关本身不发放材料；需要额外资源时显式使用已有补给按钮。此开关与按钮同样会隔离存档，不覆盖玩家的自动／手动槽。设备及配方完整规则见[15_设备建造与新手引导.md](15_设备建造与新手引导.md)。

核心入口为 `GameSession.DeveloperCompleteInteraction(panel, actor, hud)`，工具调用入口为 `DeveloperTestTools.CompleteOpenInteractions()`；开关公有字段 `skipInteractionQte`。均位于可整体移除的Development代码及编译条件内。

## 存档隔离

仅打开面板不会改存档路径。首次执行修改命令、改变跳过QTE开关或点击立即完成按钮时，将当前GameSaveManager.pathOverride临时切到Application.persistentDataPath/LifeLine/developer-test.json，后续本测试航程自动/手动存档均写此独立文件。原save-v1.json保留。返回主菜单后默认继续读取正常玩家槽；不提供独立测试档继续入口。工具移除或销毁时恢复原路径。

## 修改和删除

全部源文件位于Assets/_LifeLine/Scripts/Runtime/Development：DeveloperTestTools.cs、DevelopmentInteractionCompletion.cs和Localization/DeveloperToolsText.cs。通过RuntimeInitializeOnLoadMethod自启动，不需要场景挂载、预制体、Manager引用、Resources资产或额外程序集。可调public字段：visible、window、resourceAmount、testDay、skipInteractionQte。

直接删除整个Development目录即可移除。其他游戏脚本、场景和测试程序集没有对这些类型的依赖，不需要逐个解绑。若在Play中删除请先停止Play；正常版本构建也可通过取消Development Build自动排除。不要将工具中的命令当作玩家功能或网络可信输入，当前仅用于本地开发测试。
